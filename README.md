# macaway-site

The public landing page for MacAway, a menu bar app that locks your Mac within seconds of
you walking away, following the iPhone or Apple Watch already on you over Bluetooth.

**Not announced yet.** Notarised builds are published in the public `macaway-releases` repo
and the app updates itself from `appcast.xml` here, but nothing on the page links to them: the
Download and Buy buttons stay disabled until `DOWNLOAD_URL` and `CHECKOUT_OPEN` are set. The
app's source is in a separate private repository; only the site lives here.

## Building it

```bash
npm install
npm run build
```

The output lands in `dist/`. `npm run dev` serves it at <http://localhost:4321>.

## How it goes live

Cloudflare builds `main` on every push and serves `dist/` at <https://macaway.app>. It runs as
a Worker serving static assets, configured by `wrangler.jsonc`; Cloudflare retired Pages for
new projects. `.nvmrc` pins the Node version, because hosts default to an older one than Astro
needs.

## Counting clicks

PostHog counts page views and clicks on links, buttons and FAQ questions. It needs one build
variable:

```bash
PUBLIC_POSTHOG_KEY=phc_...            # PostHog, Settings -> Project. Not a secret.
PUBLIC_POSTHOG_HOST=https://us.i.posthog.com   # or https://eu.i.posthog.com
```

Set both in Cloudflare's build settings for the live site, and copy `.env.example` to
`.env.local` to try it locally. Without the key nothing is loaded and no events are sent,
which is what `npm run dev` gets by default.

It sets no cookies and writes nothing to the visitor's browser, so there is no consent
banner. Addresses are cut at the first `?` before they are sent, because `/thanks` carries
the Stripe session id that the licence key is worked out from. `src/lib/analytics.ts` has
the detail.

## What is in here

| | |
|---|---|
| `src/pages` | `/` and `/privacy` |
| `src/components` | header, footer, the hero, the settings panel, the shield icons, the Download button |
| `src/icons/paths.ts` | shield path data, extracted from the app's own artwork |
| `src/lib/pricing.ts` | the trial, the price, and the two switches that turn on Download and Buy |
| `src/lib/analytics.ts` | PostHog: starting it, and the one listener that counts every click |
| `public/` | the app icon, the tab icon, the self-hosted Satoshi variable font and its notice, `robots.txt` |
| `public/appcast.xml` | the update feed the app reads. Generated by Sparkle's `generate_appcast` in the app repo — never edited here (`macaway/docs/releasing.md`) |

The page carries `noindex, nofollow` and `robots.txt` disallows everything, deliberately,
until there is a release worth finding.
